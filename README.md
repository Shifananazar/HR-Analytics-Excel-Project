# HR Analytics Excel Assignment

## Project Overview
This project analyzes HR employee data using Microsoft Excel to generate workforce insights through formulas, Pivot Tables, charts, and conditional formatting.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Conditional Formatting

## Tasks Performed
- Created Attrition Risk column.
- Created Salary Band column.
- Created Promotion Eligibility column.
- Applied conditional formatting.
- Calculated Average Salary by Department.
- Identified Top 10 Highest Paid Employees.
- Analyzed Employee Engagement Score by Department.
- Evaluated Correlation between Job Satisfaction and Attrition Risk.
- Created Department vs Average Performance Rating analysis.
- Compared Salary vs Performance using a Scatter Chart.
- Identified Department with Highest Overtime Usage.
- Analyzed Hiring Trends using Pivot Charts.
